# Selected Perpeto loaders

Selected by Justus on 2026-10-17. These four animations are the preferred motion directions for the Perpeto Spindle logo.

- [Flywheel](flywheel.svg): continuous rotation.
- [Relay](relay.svg): a traveling pulse.
- [Assembly](assembly.svg): staggered separation and return.
- [Ratchet](ratchet.svg): advance, settle back, complete the turn.

Each file is a self-contained animated SVG with a transparent background and reduced-motion support. These are exact copies of the selected studies. All six original studies and static logo treatments remain in the parent folder.
