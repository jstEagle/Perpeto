# Spring studies

[Interactive preview](preview.html)

Inspired by Magnet and Recoil. Existing arms translate without turning, flipping, changing fill, or adding shapes.

- [Preload](preload.svg): A small inward draw loads an outward release.
- [Spring Return](return.svg): Arms snap home through two diminishing rebounds.
- [Pincer](pincer.svg): Opposing pairs draw in, release, then settle.
- [Slip](slip.svg): Each arm slides sideways along a tangent, then springs home.
- [Double Tap](tap.svg): A large kick is followed by a smaller echo of motion.
- [Two-stage Lock](lock.svg): Arms pause near home before snapping into place.

All files respect reduced-motion preferences.
