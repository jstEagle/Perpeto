# Arm studies

Six geometric symbol explorations built by reusing the exact upper-right arm path from the selected Spindle SVG, preserving its curved bends and angled ends. These explore a visual family before assigning final product meanings. Queue, Coordinate and Exchange were selected as promising directions. Coordinate and Exchange refinements are in [the refinement gallery](../refinements/preview.html).

[Preview](preview.html)

All six are editable SVGs with currentColor.
