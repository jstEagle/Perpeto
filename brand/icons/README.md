# Perpeto icon studies

[Compare the three directions](preview.html)

- **Draft:** thin technical outlines with gently softened joins.
- **Machined:** bold filled silhouettes with cut corners and negative-space details.
- **Modular:** square components and visible structural connections.

Each direction contains Projects, Agents, Machines, Goals, Workflow, Events, Logs, and Feedback. These are proposals for selection, not an approved production pack.

All 24 icons are original editable SVGs on a 24 × 24 grid. Use inline SVG to inherit `currentColor`; external image elements do not inherit the host text color. Provide accessible labels on controls and hide duplicate decorative icons from assistive technology. Test the chosen direction in actual product contexts before expanding it. Draft and Modular are drawn for 24px and larger; the preview includes 16px for comparison.

## Arm studies
