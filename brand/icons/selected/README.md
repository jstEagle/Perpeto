# Selected icons

User-selected icon direction: Queue (original), Coordinate (balanced), and Exchange (compact).

- [Queue](queue.svg)
- [Coordinate](coordinate.svg)
- [Exchange](exchange.svg)

Use these as the reference for future icons: solid ribbons, smooth bends, diagonal terminals, and balanced open space. New icons may use purpose-drawn geometry rather than copying a logo arm. These selections establish a visual direction; product navigation meanings remain open.

SVGs use currentColor and a 120 × 120 viewBox. Original explorations remain in their existing folders.
