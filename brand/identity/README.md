# Perpeto identity assets

- [Symbol](perpeto-symbol.svg): unchanged copy of the selected eight-arm Spindle master.
- [Wordmark](perpeto-wordmark.svg): lowercase **perpeto**, outlined from Helvetica Neue Bold with tight spacing.
- [Horizontal lockup](perpeto-lockup.svg): symbol and wordmark together.

All three are transparent, black SVGs using vector paths only: no installed font or bitmap is required to render them. To recolor, replace the black fills.

The wordmark is a clean vector companion to the selected brand-board direction. The generated boards vary in letterforms; this asset establishes a reproducible version rather than claiming an exact trace of generated lettering. The source font itself is not distributed.

The original symbol remains in `../logo/perpeto-spindle.svg`. Favorite boards are in `../overviews/favorites/`.
