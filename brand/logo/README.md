# Perpeto Spindle SVG

[perpeto-spindle.svg](perpeto-spindle.svg) is a faithful vector trace of the user's selected original eight-arm image, with a transparent background, solid black fill, square artboard, and eight separately editable paths. It contains no embedded bitmap or external dependencies.

The trace preserves the reference's individual arm shapes and slight asymmetries; it is not a reconstruction using identical rotated arms. The original remains unchanged in ../shortlist/spindle-eight-original.png.

Produced with Potrace 1.16: black threshold 0.5, speckle suppression 20, corner threshold 1.2, curve optimization tolerance 0.15, coordinate precision 0.1 source pixels. XML and path count checked, then rendered and visually inspected.
